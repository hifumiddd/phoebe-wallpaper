# 菲比 Pheobe (Wuthering Waves) 使用说明

## 首次使用与迁移

保持整个文件夹完整，双击「启动控制器.cmd」。控制器已包含 .NET 运行时，不需要开发 SDK、Python 或 Node。请解压到可写目录。

另一台 Windows x64 电脑首次需要安装 Lively 桌面版。控制器中的「获取 Lively」打开官方网站；安装后「选择 Lively」定位 Lively.exe，点击「应用此壁纸」。此包不包含 Lively，不承诺完全免安装。壁纸可离线播放；首次获取宿主需要网络。

日常将鼠标移到壁纸右下角，「静谧时光」小入口从右侧滑入；点击才展开右侧面板，× 或 Esc 收起。鼠标离开后小入口约 1.8 秒收回，启动时默认隐藏。桌面图标或其他窗口覆盖该位置时，请先露出桌面。控制器关闭窗口后留在托盘，点击托盘图标可打开备用控制面板。时间滑块支持连续拖动，拖动时自动切换为手动时间。

迁移时复制整个文件夹（包括自己添加的 Music 和 config）。新电脑需重新选择宿主并应用壁纸。不要只复制 exe。桌面时钟/音乐音量/循环偏好保存在该电脑的壁纸浏览器内，迁移后可能需要重新设置；不会自动开始播放音乐。

## 昼夜与时钟

清晨、正午、黄昏、原画夜晚（21:00）、午夜组成时间循环。滑块用于手动选择；「跟随本地时间」使用 Windows 时间。原画模式保留原画色彩。原始素材没有被修改。

左下角时钟始终显示真实本地时、分、秒，手动选择壁纸时段不会改变钟面时间。时钟颜色随壁纸昼夜氛围变化；原画模式采用柔和冷色。可在面板关闭「显示桌面时钟」。这是融入色调的叠加时钟，不是重绘画面内的实物钟。

## 本地音乐

1. 将音乐文件放入本包的 Music 文件夹，也可通过托盘控制器的「打开音乐文件夹」进入。
2. 控制器保持运行，点击壁纸面板「更新曲库」，或者托盘控制器的同名按钮。
3. 在「窗边留声」选择曲目，点击「播放音乐」。音量和单曲循环可直接调节。

只读取 Music 第一层，最多 100 首，按文件名排序。接受 MP3、WAV、M4A、AAC、FLAC、OGG 扩展名；实际编码支持取决于 Lively 浏览器，优先使用 MP3/WAV。不自带音乐。更新时将音乐副本复制到此壁纸的 Lively 库，因此会额外占用相应磁盘空间；删除/替换后再次更新即可。

默认不自动出声。Lively 因全屏遮挡暂停壁纸时，音乐同步暂停，返回桌面仅恢复此前正在播放的音乐；手动暂停不会被自动取消。「暂停动态」也会暂停音乐。宿主全屏暂停策略需启用；若修改 Lively 的播放规则，音乐跟随宿主实际发出的暂停状态。停止/重载壁纸会停止音乐，下次需点击播放。

关闭单曲循环后按曲库顺序播放，末尾回到首曲。本版不支持在线音乐、子目录扫描或系统媒体键。

## 性能与验证范围

提供 15/30/60 fps。时钟每秒更新，不进行逐帧计算；宿主暂停时停止隐藏时钟定时器，恢复时立即校准。没有为省资源降低原画分辨率或移除动态。

本版新增功能经过状态回归、曲库文件同步测试及浏览器检查。此前宿主长稳与性能结果只覆盖原有渲染路径；不将其冒充新音乐模块的长稳测试。多屏、不同音频编码、睡眠恢复及其他电脑环境仍需实际验证。

退出控制器后壁纸继续工作，但曲库更新需要重新启动控制器。升级时保留 Music 与 config。对外分享需自行确认原画与音乐授权。

面板顶部「语言 / Language」可切换中文与 English，选择自动保存在本机，重载后保留。仅切换内嵌壁纸 UI，不改变壁纸时间、动态和音乐参数。

面板右侧滚动条支持拖动。Lively 桌面滚轮补传递需要托盘控制器保持运行，仅在面板展开且鼠标位于面板内时处理；关闭控制器后仍可拖动滚动条。滚轮与拖动均已在本机 Lively 桌面验证通过。日常双击「启动控制器.cmd」即可；控制器窗口可关闭到托盘，无需一直显示窗口。
