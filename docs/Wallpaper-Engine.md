# 菲比 Pheobe (Wuthering Waves)

清晨、正午、黄昏、原画夜晚与午夜；窗帘与微尘动态，以及随光照变化配色的真实时钟。本作品无 BGM。

鼠标移到壁纸右下角，小入口从右侧滑入；点击「静谧时光」展开控制面板。× 或 Esc 关闭，离开入口约 1.8 秒后自动收回。入口启动时隐藏，请露出桌面再操作。

时间滑块可连续调整壁纸时段；「跟随本地时间」使用系统时间。时钟始终显示真实时间。原画夜晚保留原图氛围。参数在本机保存。

流畅度提供 15/30/60 fps。当 Wallpaper Engine 设置的帧率更低时，显示「宿主限制」，实际遵守较低上限。全屏暂停由 Wallpaper Engine 的播放规则控制，返回桌面后自动恢复。

面板顶部「语言 / Language」可切换中文与 English，选择自动保存在本机，重载后保留。仅切换内嵌壁纸 UI，不改变壁纸时间、动态和音乐参数。
