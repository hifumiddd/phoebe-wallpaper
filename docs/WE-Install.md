# Wallpaper Engine 本地安装

1. 通过 Steam 安装并启动 Wallpaper Engine。
2. 完整解压此 ZIP。将 phoebe-web 文件夹放入 Wallpaper Engine 安装目录下的 projects/myprojects/。
3. 确认目录结构为 projects/myprojects/phoebe-web/project.json，避免多套一层文件夹。
4. 重新打开 WE 界面，在已安装壁纸中选择「菲比 Phoebe」。若未显示，在编辑器导入 phoebe-web/index.html；所有旁边的 JS、图片、lib 文件必须保留。
5. 鼠标靠近桌面右下角，点击滑入的小入口打开面板。可切换中文/English、拖动时间或跟随系统时间。

需要 WE；不需要 Lively 或控制器。无 BGM。不要在同一个桌面同时运行两个壁纸宿主。
全屏暂停与返回恢复遵从 WE 的播放设置；首次使用请确认鼠标交互已启用。
此文件夹是本地导入包，不带作者的 Workshop 更新关联，不会自动上传。
